# Writeup widgets & data

Interactive results widgets embedded in the selective-learning doc
(https://docs.nielsrolf.com/documents/cmry4vfv8009y90afkafn7elr).

- `widgets/build_results_widget.py <task> [--remote <base_url>]` — builds `assets/results_<task>.html`.
- `data/payload_<task>.json` — widget payload (meta + per-response scores + v2 summary). Served to the doc widgets via jsDelivr (`https://cdn.jsdelivr.net/gh/nielsrolf/spar-localized-finetuning@<sha>/shared/writeup/data/`).
- `data/summary_v2.json` — aggregate capability/UG means extracted from `sunday/scripts/eval/plot_v2_tradeoffs.py` (v2 jobs from the training-jobs sheet, judge deepseek-v4-flash).
- `data/responses_<task>.json` — per-response completions + judge scores from the archived layer-freezing sweep (`sunday/scripts/archive/layerfreeze/eval/csv_results/gpt54nano_10samples_raw/`, judge gpt-5.4-nano). Only 5 tasks have these; v2 per-response artifacts live in OpenWeights job storage and need an API key to download.

Generated by claudex (SPAR channel bot), 2026-07-23.
